# Track Session Minder

A track day (HPDE) schedule app for iPhone and Android. Drivers see which run
group is on track now, who is up next, and the full day's schedule. An admin
can shift the schedule when the day runs late.

Built with [Expo](https://expo.dev) (React Native) and Expo Router.

## What's here

- `src/app/` – the three screens: **Now**, **Schedule** and **Admin**
- `src/data/sampleEvents.ts` – the Roebling and Barber schedules, copied from the Just Track It PDFs
- `src/lib/schedule.ts` – time math: what's on track now, what's next, shifting the day when running late
- `src/lib/ScheduleStore.tsx` – loads the events and listens for live changes
- `supabase/` – the online database setup (`setup.sql` is generated by `npx tsx scripts/generate-setup-sql.ts`)

## Online database

Schedules live in [Supabase](https://supabase.com). Anyone can read them,
and every change reaches open apps within seconds. Each event belongs to a
club: a club's admins can change only that club's events, and platform
admins (Redline Techniques) can change everything. `supabase/admin-snippets.sql`
has copy-and-paste SQL for adding clubs and admins. Club logos live in
`assets/clubs/` (or a club's `logo_url`).

1. Run `supabase/setup.sql` in the Supabase SQL Editor (again after updates that change it; it only adds what's missing).
   The first run makes the accounts that already exist platform admins.
2. Add admins under Authentication → Users. Being signed in gives no editing
   rights by itself: only people listed in `platform_admins` or `club_admins` can edit.
3. Put the project URL and publishable key in `.env`:
   `EXPO_PUBLIC_SUPABASE_URL=...` and `EXPO_PUBLIC_SUPABASE_KEY=...`

Without `.env`, the app runs on the built-in sample events in practice mode.

### Coaching sessions and driver sign-in

Admins book a paid coaching session for one student by email (Admin tab →
Coaching). The student signs in on the Me tab with a one-time code emailed to
them, then sees the session on Me, on Now (with a countdown) and on Schedule.
Only that student and the club's admins can see it. A session is linked to a
schedule item, so "running late" shifts move it too.

Driver sign-in needs three settings in Supabase:

1. Authentication → Sign In / Providers: turn on **Allow new users to sign up**.
2. Authentication → Emails → Templates: in **Magic Link** and **Confirm signup**,
   add the code to the message, for example `<p>Your code: {{ .Token }}</p>`.
3. Authentication → Emails → SMTP Settings: set up a custom email sender
   (for example Resend or SendGrid). Supabase's built-in sender only emails
   the project's team members and only a few emails an hour.

## Website version

Every push to `main` publishes the web version to GitHub Pages
(`.github/workflows/deploy-web.yml`).

## Running it

```bash
npm install
npx expo start        # then scan the QR code with the Expo Go app on your phone
npm run typecheck
node scripts/build-preview.mjs dist/preview.html   # one-file web preview
```
